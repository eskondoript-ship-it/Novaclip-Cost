Um projecto para a turma

Vídeos feitos para os avós

Cada aluno explica uma coisa real a alguém de oitenta anos. Como renovar a receita. Como ver que a mensagem do banco é falsa. Como fazer uma videochamada.

O que treinam

Escrever sem jargão. Letra grande. Contraste a sério. Ritmo lento.

Porque resulta

O vídeo tem um destinatário com nome. Isso muda a forma como o aluno o julga.

E responde a

“Isto é só para fazer TikToks.” Aqui o produto é para outra pessoa.

E os vídeos têm onde ir: o NovaClassics é o site desse público. A turma faz, eles usam.

Guardar para quando alguém disser que isto é só para o feed deles. É a resposta e é concreta: os mesmos alunos, as mesmas ferramentas, outro destinatário. O NovaClassics fecha o círculo — não é um exercício imaginário, há um sítio onde o trabalho serve. Sugerir que o piloto seja este projecto: avaliação fácil, resultado visível para as famílias, e uma coisa para mostrar numa reunião de pais. Se perguntarem por lares ou centros de dia em Belém, é a escala certa para começar.
